# 型动健身 · 官网

型动健身（XINGDONG FIT）Web 端官网原型。

基于 benjamincreative.me 风格设计，黑白 + 荧光绿视觉语言，包含：

- 首屏巨字标题 + 肌肉女主视觉
- 产品理念宣言（Be Real / Be Strong / Be Bold）
- 课程列表（6 门课程，hover 滑入对应照片）
- 3D 动作库 + AI 计划 + 语音督导功能介绍
- 打字机宣言文案
- Canvas2D ASCII 点阵背景
- 壶铃鼠标跟随 + 拖影效果
- 双向滚动动画（回滚重复触发）

## 技术栈

- 纯 HTML + CSS + 原生 JS（单文件）
- Canvas2D 动画
- IntersectionObserver 滚动触发
- 无构建工具，无框架依赖

## 本地运行

直接用浏览器打开 `index.html` 即可。
