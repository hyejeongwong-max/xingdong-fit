# 型动健身 · XINGDONG FIT

> 你的 AI 私教，基于居家训练。

一个现代化的健身 App 落地页，展示 AI 定制训练计划、3D 动作库、语音跟练等核心功能。纯静态 HTML + CSS，可直接部署到 GitHub Pages。

![fitness](https://aka.doubaocdn.com/s/HYpGloVL1e)

## ✨ 特性

- **500+ 3D 动作库** — 目标肌群高亮，常见错误提醒
- **21 天 AI 定制计划** — 智能强度调整，训练数据复盘
- **10–30 分钟碎片化课程** — 语音督导跟练，节拍呼吸提醒
- **响应式设计** — 适配桌面、平板、手机
- **零依赖** — 纯 HTML + CSS，无需构建工具

## 🚀 本地预览

直接用浏览器打开 `index.html` 即可，或启动一个本地服务器：

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 🌐 部署到 GitHub Pages

1. 将本仓库推送到 GitHub
2. 进入仓库 **Settings → Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选择 `main`，目录选择 `/ (root)`
5. 保存后等待部署完成，访问 `https://<你的用户名>.github.io/<仓库名>/`
